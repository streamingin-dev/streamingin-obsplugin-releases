# Streamingin for OBS — downloads

Release binaries for the Streamingin OBS plugin. The plugin source (GPLv2) is
at https://github.com/streamingin-dev/streamingin-obsplugin.

Install: unzip into `C:\ProgramData\obs-studio\plugins\` so you end up with
`streamingin-obspluginin4bit\` and `streamingin-obsplugin\data\`, then start OBS.
No Streamingin desktop app is required.
